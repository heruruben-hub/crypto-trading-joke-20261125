Entry for **Laugh Track: The Crypto Trading Joke Contest** on
[make.fun](https://make.fun/c/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a):
a program that writes one original one-line joke about crypto and trading
life to `/output/entry.txt`.

## The joke

> I bought the dip. Then the dip dipped. Now I own the whole staircase.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library and writes exactly one line
(69 characters, no trailing newline) to `/output/entry.txt`.
